### Codify — Plateforme d'apprentissage de la programmation assistée par IA
`PFA 2026` · [Voir le code](https://github.com/Ibtihel-Gritli/Codify)

Conception et développement d'une plateforme Full-Stack assistée par IA pour apprendre à programmer.

- Gestion des utilisateurs, exécution de code et fonctionnalités d'apprentissage personnalisé
- Intégration de l'API **Groq (Llama 3.3-70B)** pour l'analyse, la correction et l'optimisation du code, avec des retours adaptés au niveau de l'utilisateur
- Assistant IA interactif et transformation de code entre différents langages
- Hackathons de programmation en temps réel avec **WebSocket / STOMP**, chronomètres synchronisés, exercices personnalisés, leaderboard et gamification
- Méthodologie **Scrum** : 5 sprints et 21 user stories

### ShopFlow — Plateforme e-commerce Full-Stack
`Projet académique 2026` · [Voir le code](https://github.com/Ibtihel-Gritli/ShopFlow-)

Plateforme e-commerce avec trois rôles (**Admin, Vendeur, Client**) : produits, panier, commandes, avis et promotions par coupons.

- Architecture backend en couches : API REST, **Spring Data JPA**, DTO et services transactionnels
- Authentification sécurisée avec **JWT** et **Spring Security**, autorisations par rôles
- Gestion des **access tokens** et **refresh tokens** pour protéger les endpoints
- Intégration frontend / backend en REST sécurisé avec **Axios Interceptors** et composants Next.js réutilisables
- Documentation des APIs avec **Swagger**
