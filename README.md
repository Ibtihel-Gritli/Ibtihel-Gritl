## Projets

### Codify — Plateforme d'apprentissage de la programmation assistée par IA
`PFA 2026` · [Voir le code](https://github.com/Ibtihel-Gritli/Codify)

Plateforme Full-Stack qui aide à apprendre la programmation grâce à l'IA.

- Gestion des utilisateurs, exécution de code et parcours d'apprentissage personnalisé
- API **Groq (Llama 3.3-70B)** pour analyser, corriger, optimiser et transformer du code entre langages, avec des retours adaptés au niveau de l'utilisateur
- Assistant IA interactif intégré à l'éditeur
- Hackathons en temps réel avec **WebSocket / STOMP** : chronomètres synchronisés, exercices adaptatifs, classement et gamification
- Méthodologie **Scrum** : 5 sprints et 21 user stories

`Spring Boot 3` `Java 17` `Thymeleaf` `MySQL` `Bootstrap 5` `JavaScript` `Groq API` `WebSocket`

### ShopFlow — Plateforme e-commerce Full-Stack
`Projet académique 2026` · [Voir le code](https://github.com/Ibtihel-Gritli/ShopFlow-)

Plateforme e-commerce avec trois rôles (**Admin, Vendeur, Client**) : produits, panier, commandes, avis et promotions par coupons.

- Backend en couches : API REST, **Spring Data JPA**, DTO et services transactionnels
- Authentification **JWT** et **Spring Security**, autorisations par rôles, gestion des *access* et *refresh tokens*
- Frontend Next.js avec **Axios Interceptors** et composants réutilisables, persistance du panier
- APIs documentées avec **Swagger**

`Spring Boot 3` `Next.js` `Spring Data JPA` `JWT` `Lombok` `H2` `Maven` `Swagger`
