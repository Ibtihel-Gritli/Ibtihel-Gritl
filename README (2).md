### 🏪 [ShopFlow](https://github.com/Ibtihel-Gritli/ShopFlow-) — Plateforme e-commerce Full-Stack *(Académique 2026)*

> Développement d'une plateforme e-commerce Full-Stack avec Spring Boot et Next.js, intégrant la gestion des produits, du panier, des commandes, des avis et des promotions par coupons.

**Contributions clés :**
- 🏗️ Architecture backend en couches : API REST, Spring Data JPA, DTO et services transactionnels
- 🔐 Authentification sécurisée avec JWT et Spring Security, et gestion des autorisations par rôles (Admin / Vendeur / Client)
- 🔁 Gestion des access tokens et refresh tokens pour sécuriser les endpoints
- 🔗 Intégration frontend / backend via REST sécurisé avec Axios Interceptors et composants Next.js réutilisables
- 🧺 Catalogue, panier persistant, commandes et coupons
- 📄 Documentation des APIs avec Swagger

**🛠️ Stack :** `Spring Boot 3` · `Next.js` · `Spring Data JPA` · `JWT` · `Lombok` · `H2` · `Maven` · `Swagger`
